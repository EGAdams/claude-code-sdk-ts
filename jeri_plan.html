1. Who Jeri Is

Jeri is a stateful Letta agent whose domain of mastery is the claude-code-sdk-ts TypeScript SDK repo. She runs on mom's Letta server, participates in the local multi-agent mesh via Letta's agent-to-agent messaging, and simultaneously exposes herself as a discoverable Google A2A endpoint so any standards-compliant agent (on any vendor stack) can delegate work to her over HTTP/JSON-RPC 2.0.

2. Technology Primers

Letta — Stateful Agent Platform

Letta (formerly MemGPT) is a server that hosts long-lived agents with persistent memory. Each agent gets memory blocks (persona, human, custom) and a list of attached tools (Python functions).

Key API calls

from letta_client import Letta

client = Letta(base_url="http://10.0.0.143:8283")

# Create agent
agent = client.agents.create(
  name="jeri-agent",
  model="anthropic/claude-sonnet-4-6-20250514",
  memory_blocks=[...],
  tools=["read_sdk_file", "run_typescript", ...]
)

# Attach an extra tool later
client.agents.tools.attach(agent_id, tool_id)

Agent-to-Agent

Letta agents share a shared memory block or call each other via injected client inside a tool — client.agents.messages.create(agent_id, [msg]).

Google A2A Protocol

Open standard (Apr 2025, 150+ orgs). Agents discover each other via an AgentCard at GET /.well-known/agent.json and delegate work as Tasks over HTTP + JSON-RPC 2.0.

JSON-RPC Handler Skeleton

import express from "express";
import { CapabilityRegistry } from "../capabilities";

const app = express();
app.use(express.json());

app.get("/.well-known/agent.json", (_req, res) => res.json(AGENT_CARD));

app.post("/", async (req, res) => {
  const { method, params, id } = req.body;
  switch (method) {
    case "SendMessage":
      return handleSendMessage(params, id, res);
    case "SendStreamingMessage":
      return handleSSE(params, id, res);       // res.writeHead(200, SSE headers)
    case "GetTask":
      return handleGetTask(params, id, res);
    case "CancelTask":
      return handleCancel(params, id, res);
    default:
      res.json({ jsonrpc: "2.0", id, error: { code: -32601, message: "Method not found" } });
  }
});

Communication tools

def send_a2a_task(
    agent_url: str,
    skill_id: str,
    message: str
) -> str:
    """
    Delegate a task to another A2A agent.

    Args:
        agent_url (str): Base URL of the target agent
        skill_id (str): Skill to invoke
        message (str): Task description/payload

    Returns:
        str: JSON-serialized Task result
    """
    payload = {
        "jsonrpc": "2.0", "method": "SendMessage",
        "id": str(uuid.uuid4()),
        "params": {
            "message": {
                "role": "ROLE_USER",
                "parts": [{"text": message}]
            },
            "skill": skill_id
        }
    }
    r = requests.post(agent_url, json=payload)
    return r.text

def send_letta_message(
    agent_id: str, message: str
) -> str:
    """
    Send a message to another Letta agent.

    Args:
        agent_id (str): Target Letta agent ID
        message (str): Message content

    Returns:
        str: Agent reply
    """
    # 'client' is auto-injected by Letta
    result = client.agents.messages.create(
        agent_id=agent_id,
        messages=[{"role": "user", "content": message}]
    )
    return str(result)
Letta client injection: When Letta calls a tool that uses client as a parameter name, Letta automatically injects a pre-initialized Letta client. You also get LETTA_AGENT_ID as an env var. No manual auth needed inside tools.

Capability Implementations

~4–6 hours

Wire up each of the five capabilities. Each one follows the same pattern: accept a normalized ITaskRequest, call the fluent Claude SDK, stream chunks back, return an ITaskResponse.

Shared SDK wrapper pattern

import { claude } from "../../src/fluent";  // local file: ref

export async function runCapability(
  prompt: string,
  role: string,
  onChunk: (chunk: string) => void
): Promise<string> {
  const builder = claude()
    .withRole(role)
    .withPermissions({ allowedTools: [] }) // scope: read-only
    .withTelemetry(jeriTelemetry);

  let full = "";
  await builder.ask(prompt).stream((chunk) => {
    full += chunk;
    onChunk(chunk);
  });
  return full;
}

8. Scope Guard & Safety Rules

Jeri must not read or write outside her allowed paths. Implement IScopeGuard (from blueprint) as a simple path prefix check applied before every file operation.

  • Read allowed: /home/adamsl/claude-code-sdk-ts/** and $JERI_ARTIFACT_ROOT/** and the January statements dir
  • Write allowed: $JERI_ARTIFACT_ROOT/** only
  • Never: ~/.ssh, .env, any path outside the above
  • npm scripts allowed: build, test, typecheck, lint, format — no others
function assertAllowed(path: string): void {
  const allowed = [SDK_ROOT, ARTIFACT_ROOT, STATEMENTS_DIR];
  if (!allowed.some(r => path.startsWith(r))) {
    throw new ScopeViolationError(`Access denied: ${path}`);
  }
}

10. Jedi Knighthood Criteria

  1. SDK Mastery: Given only a Letta prompt, she reads src/fluent.ts, explains the fluent chain, and writes a working TypeScript snippet using it.
